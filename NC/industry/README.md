# VEC.VirtualMarketplace · Industrie‑6.0‑Router

Der VEC‑Industrie‑Kern ist kein Marktplatz.
Er ist der Routing‑Kern der Industrie‑6.0‑Architektur.

Er verbindet:

- NC.engine → Bewegung
- GEO.physik → Kraft
- GEO.geo → Segment
- DYN → Achse
- SURE → Stand
- NEO → Höhe/Breite/Tiefe
- HARDWARE → CPU/RAM/ROM/GPU

VEC dient hier nicht dem Handel,
sondern der technischen Verbindung aller Industrie‑Module.

## Funktionen
- Industrie‑Routing (Segment → Achse → Kraft)
- Übergänge zwischen technischen Modulen
- Bewertung technischer Impulse (GENIE.tech)
- Kontrolle über DOO/IT.tech
- Durchlass über DOOR.tech + API.tech
- Neutralisierung über ZEN.tech

## Dateien
- API.raw → Rohdefinition des Industrie‑Kerns
- API.system.js → technische Funktionslogik
- ID.html → Industrie‑Identität
- index.html → Industrie‑Routing‑Oberfläche

VEC ist hier ein Industrie‑Router,
nicht ein Marktmodul.
