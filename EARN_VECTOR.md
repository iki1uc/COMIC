# EARN / VECTOR

EARN = Tatbestand.  
VECTOR = Vorgang.

EARN trägt QI.  
VECTOR trägt IQQ.

Tatbestand + Vorgang = Ausgang.  
Ausgang → Bewegung.  
Bewegung → VECTOR.  
VECTOR → Sieger.

QI = Reinheit des Tatbestands.  
IQQ = Reinheit des Vorgangs.

Hohe Reinheit → offenes Continuum.  
Niedrige Reinheit → nochance.vector.

EARN ist Ursprung.  
VECTOR ist Richtung.  
Ausgang ist Klarheit.
