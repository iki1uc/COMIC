Mechanik – Funktionsweise

MECHANIK = ORT → TMP → ACHSE → LAGE → laTER → RAUM → QUANT → SYN

ORT  = Ursprung / Koordinate
TMP  = Zwischenform / temporale Struktur
ACHSE = Neutralpunkt → Continuum → Sprung
LAGE = Position im Raum
laTER = Rückkehr / spätere Form
RAUM = Ausdehnung / Tiefe / Breite / Höhe / Trans
QUANT = Verdichtung / Intensität
SYN = Synchronität / Puls / Frequenz
